We propose CoCo (Code-as-CoT), a code-driven reasoning framework for text-to-image generation. CoCo generates executable code that specifies the structure of a scene, renders a deterministic draft image in a sandbox, and refines the draft into a high-fidelity result. We also introduce CoCo-10K, a dataset of structured draft-final image pairs for learning this workflow.
